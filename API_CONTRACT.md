# API Contract

## Friends
- `POST /friends/request/{friend_id}`
- `POST /friends/accept/{friend_id}`
- `POST /friends/reject/{friend_id}`
- `DELETE /friends/remove/{friend_id}`
- `GET /friends/list`

## Auth
- `POST /auth/register`
- `POST /auth/login`
- `GET /auth/me`
